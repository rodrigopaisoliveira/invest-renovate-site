# Quest Remodel Hub

Cria um website institucional para a InnovateQuest, uma empresa de remodelações que trabalha tanto com particulares como com investidores.

Objetivo do site:
O objetivo principal é gerar pedidos de orçamento. O fluxo de contacto deve priorizar: 1) WhatsApp, 2) Chamada telefónica, 3) Email (como opção mais formal). O botão de "Solicitar Orçamento" deve estar sempre visível e ser o principal call-to-action da página.

Estrutura (landing page, single page com scroll suave entre secções, navbar fixa):

Início — Hero section com imagem/vídeo de destaque de uma remodelação, título forte, subtítulo curto e botão principal "Solicitar Orçamento"

Serviços — Apresentação dos serviços de remodelação, divididos claramente entre soluções para Particulares e soluções para Investidores (usar cards ou secções separadas)

Sobre Nós — Espaço para texto institucional + fotos da equipa/trabalhos (vou fornecer o conteúdo depois)

Contacto — Botões diretos para WhatsApp e chamada, email visível, e possivelmente um mapa/localização se aplicável

Solicitar Orçamento — Formulário simples (nome, contacto, tipo de projeto, breve descrição) que envia para WhatsApp como prioridade, com alternativa por email

Estilo e Design:

Estilo moderno, limpo, profissional, com foco em confiança e credibilidade (setor de construção/remodelação)

Funcionalidades técnicas:

Site rápido, leve, otimizado para SEO básico

Fácil de editar/atualizar (texto e imagens) — cliente não tem conhecimentos técnicos

Integração com Instagram (link/ícone no footer e/ou secção de contacto)

Formulário de orçamento funcional, a integrar com WhatsApp Business API ou link direto wa.me
